# SemiGuard AI

**반도체 신입 엔지니어를 위한 AI 장비 판단 훈련 플랫폼**

> 고장을 외우는 교육에서, 이상을 판단하는 교육으로.

SemiGuard는 고장을 대신 확정하는 시스템이 아닙니다. 교육용 가상 장비·검사 기록을 관찰하고, 정상 참고와 비교하고, 판단 근거를 직접 작성한 뒤 피드백과 복기로 다시 배우는 웹 플랫폼입니다.

[사이트 열기](https://semiguard-ai-five.vercel.app/) · [로그인 없는 30초 샘플](https://semiguard-ai-five.vercel.app/preview) · [8대 공정 학습](https://semiguard-ai-five.vercel.app/learn) · [로그인하고 연습 시작](https://semiguard-ai-five.vercel.app/training)

**모든 기본 데이터는 교육용 가상 데이터입니다. 실제 팹 연결·장비 제어·고장 확정 진단은 제공하지 않으며, 현장 정확도나 학습 효과는 검증된 성과로 주장하지 않습니다.**

## 왜 만들었나요?

공정 원리와 센서의 의미를 배워도, 여러 신호가 함께 변하는 상황에서 판단 과정을 반복 연습하기는 어렵습니다. 실제 장비에서 실수하기 전에 다음 질문을 안전한 가상 환경에서 직접 확인하도록 만들었습니다.

- 정상 상태와 무엇이 다른가?
- 어떤 신호가 먼저 변했으며, 다른 기록과도 일치하는가?
- 지금 쓴 내용은 관찰한 사실인가, 원인에 대한 추정인가?
- 다음에 어떤 기존 기록을 비교해야 판단을 보완할 수 있는가?

## 이용 흐름

**소개 → 로그인 또는 샘플 보기 → 연습 방식 선택 → 관찰·판단 기록 → 제출 → 기준 피드백·선택적 AI 코칭 → 타임라인 복기**

로그인 없이 소개, 공정 개념, 30초 샘플을 볼 수 있습니다. 본 판단 훈련·AI 요청·개인 기록은 로그인 후 이용합니다. 8대 공정 학습을 모두 읽거나 특정 연습을 통과해야 다른 모드가 열리는 구조는 아닙니다.

## 무엇을 할 수 있나요?

| 공간 | 하는 일 | 다른 공간과의 차이 |
| --- | --- | --- |
| **8대 공정 학습** | 공정 원리, 개념 그림, 장비 사례, 관찰할 근거와 자가 확인 | 판단 연습 전에 필요한 맥락을 익히는 Learning Hub |
| **8대 공정 판단 연습** | 공정별 가상 기록 관찰, 변화 시점·근거 선택, 서술형 답안, 제출·복기 | 준비된 기록으로 자신의 판단 과정을 되짚는 연습 |
| **실시간 자유 분석** | 가변 가상 식각 스트림 또는 CSV를 관찰하고 여러 메모 기록 | 정해진 제출 답안·훈련 종료 없이 자유롭게 비교하는 공간 |
| **4센서 대시보드** | 전류·온도·진동·소음 그래프, 정상 참고, 규칙 점수 기여도·이력, AI 설명 | 단위가 다른 신호를 함께 해석하는 별도의 가상 관측 공간 |
| **내 학습 기록** | 제출한 시도 상세·타임라인 재확인, 선택 답안 공유, 저장한 연습 이어하기 | 로그인 계정별 기록을 다시 읽고 반복 연습 |

실시간 자유 분석의 메모는 **현재 브라우저 탭의 임시 저장**이며 계정 동기화 대상이 아닙니다. 필요한 메모는 파일로 내려받을 수 있습니다. CSV는 브라우저에서 읽으며, 해당 화면에서 외부 AI로 자동 전송하지 않습니다. 실제 회사 자료 대신 제공되는 가상 예시로 연습하세요.

### 8개 판단 연습

웨이퍼 제조 → 산화 → 포토 → 식각 → 증착·이온 주입 → 금속 배선 → EDS → 패키징 순서로 구성했습니다. 필요한 모듈부터 선택해도 됩니다.

각 모듈에는 관련 장비의 **공개 제조사 자료와 설명**이 있습니다. 장비 사례는 공정 맥락을 이해하기 위한 참고이며, 가상 지수·기준 띠·변화 시점의 출처가 아닙니다. 식각은 가상 챔버의 압력·유량·전력·온도를 비교하고, 다른 모듈은 해당 공정에 맞는 가상 검사·시험 기록을 비교합니다. 검사 결과와 장비 상태를 같은 근거로 단정하지 않습니다.

구현 근거: [공정별 연습 정의](shared/processScenarios.ts), [장비 사례·출처](shared/processEquipment.ts), [공정 개념 그림](shared/processVisuals.ts).

### AI Judgment Coach와 학습 도우미

AI 코칭은 제출한 답안과 가상 기록의 관계를 설명하고, 근거를 다시 확인할 질문을 제안합니다. 학습 도우미는 공정 개념과 제품 이용 질문을 돕고, 4센서 상담은 해당 화면에서 제공된 센서 근거를 바탕으로 설명합니다.

- **기준 피드백**은 선택 항목에 대한 교육용 규칙 평가입니다. 생성형 AI가 점수나 정답을 결정하지 않습니다.
- **AI 코칭**은 NVIDIA 모델의 생성 답변입니다. 요청 전에 전송 안내·동의를 확인하며, 사실 정확성이 보장되는 진단 결과는 아닙니다.
- 코칭 요청이 실패하면 실패 상태를 알리고 기준 피드백·복기를 유지합니다. 준비된 문구를 AI가 생성한 답변처럼 표시하지 않습니다.
- 여러 창의 계정 기록을 한 장비의 연속 측정으로 단정하지 않습니다. 질문에 제공되지 않은 개인 기록을 AI가 읽었다고 주장하지 않습니다.

자세한 데이터·제공자·IP 경계는 [AI 활용 및 안전 고지](AI_USAGE.md)를 확인하세요.

### 로그인하면 달라지는 점

Google·네이버·카카오 소셜 로그인과 일반 계정을 지원합니다. 로그인 계정별로 제출 기록을 저장·조회하고, 직접 중간 저장한 **재생 위치와 선택 답안**을 불러와 이어갈 수 있습니다. 훈련의 서술형 원문과 AI 코칭 원문은 학습 기록 DB에 저장하지 않습니다.

공유는 선택 답안과 그에 따른 가상 기록 복기용 링크입니다. 이름·계정 식별자·서술형 원문·AI 답변을 공유하지 않으며, 링크는 **7일 후 만료**됩니다. 중간 저장, 제출 완료 기록, 자유 분석의 임시 메모는 서로 다른 저장 범위입니다.

## 기술 구조

| 계층 | 주요 기술·역할 |
| --- | --- |
| 화면 | React · TypeScript · Vite · Tailwind CSS · Recharts |
| API | Express · tRPC · 입력 검증과 사용자 소유권 확인 |
| 저장 | Drizzle ORM · MySQL/TiDB · 계정별 제출 기록과 중간 저장 |
| AI 설명 | 서버 전용 NVIDIA 연동 · 응답 형식·근거 검증 |
| 학습 시각 자산 | 대회용 OGQ API · 안내용 스티커와 출처 표시 |
| 검증·배포 | TypeScript · Vitest · Vercel |

4센서의 위험 점수는 **z-score 기반 규칙형 계산**입니다. Isolation Forest나 학습된 고장 분류 모델이 아니며, 위험 점수는 고장 확률이 아닙니다. 8대 공정 연습의 기준 평가와도 구분합니다.

## 실행과 검증

[package.json](package.json)의 `packageManager`에 지정된 pnpm을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

계정 기능에는 `DATABASE_URL`, `JWT_SECRET`, `VITE_APP_ID` 및 준비된 DB 스키마가 필요합니다. 소셜 로그인에는 각 제공자 ID·Secret과 callback 등록이 필요하며, NVIDIA 코칭은 `NVIDIA_API_KEY`, OGQ 안내 이미지는 `OGQ_API_KEY`를 서버 환경에서 사용합니다. 현재 환경변수 이름과 AI 기본 모델은 [서버 환경 설정](server/_core/env.ts)을 기준으로 확인하세요.

키와 DB 접속값은 로컬의 Git 제외 환경 파일 또는 배포 서버의 Secret에만 저장합니다. `VITE_`로 시작하는 이름에 비밀키를 넣거나 GitHub·스크린샷·채팅에 실제 값을 올리지 않습니다. DB 마이그레이션은 별도의 테스트 DB에서 검토하며 운영 DB에 자동 실행하지 않습니다.

```sh
pnpm check
pnpm test
pnpm build
```

타입 검사 → 전체 테스트 → production build 순서로 확인합니다. 로컬 성공은 운영 로그인·DB·외부 AI 성공과 다르므로 배포 후 실제 흐름을 별도로 확인합니다. Vercel 설정은 [vercel.json](vercel.json), API 진입점은 [api/index.mjs](api/index.mjs)입니다.

## 모바일·언어

한국어·영어·일본어 화면을 제공하며 휴대폰·태블릿 브라우저에서도 사용할 수 있습니다. iPhone에서는 Safari의 **공유 → 홈 화면에 추가**로 앱처럼 열 수 있습니다. App Store에 등록한 네이티브 앱이 아니며, 로그인·저장·AI 요청에는 온라인 연결이 필요합니다.
