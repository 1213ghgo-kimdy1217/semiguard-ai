# 과거 개발·제출 기록

[최신 제품 README](../../README.md) · [현재 문서 안내](../README.md)

루트에 흩어져 있던 문서를 별도로 보관하고, 문서 위에 과거 기록임을 표시했습니다. 공개 문서에 남아 있던 테스트 로그인 비밀번호와 소셜 계정 식별자는 제거했으며, 개발·제출 이력은 유지합니다. 큰 누적 작업 로그 `legacy/todo.md`와 감사 JSON은 내용 수정 없이 원본 그대로 옮겼습니다. **예전 URL, 기능 상태, 시험 수치와 파일럿 계획은 현재 완료 증거가 아닙니다.**

감사 JSON은 이번 정리 이전에 생성된 원본 출력입니다. 파일을 보관한 사실이 최신 보안 점검 통과를 뜻하지 않습니다. 재생성되는 감사 출력은 루트에 다시 커밋하지 않도록 제외했습니다.

앱에서 사용하는 아이콘·소스·테스트·개발 및 배포 설정·라이선스는 유지합니다. 이 정리는 Git 이력 삭제나 사용자 데이터 삭제를 포함하지 않습니다.
