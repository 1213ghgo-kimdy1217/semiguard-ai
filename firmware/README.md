# SemiGuard 부스 프로토타입 펌웨어

이 펌웨어는 **물리 버튼 입력과 LED 제어 명령**을 웹에 전달합니다. 실제 압력·가스 유량·RF 전력·공정 온도를 측정하지 않습니다. 웹의 공정 그래프는 이 입력을 활용한 교육용 모의 값입니다. `ledCommand`도 LED에 보낸 명령이며 빛을 센서로 확인한 값은 아닙니다.

## 배선과 준비

아래 배선은 **Arduino UNO 기준**입니다. 실제 보드 모델을 확인한 뒤 IDE에서 보드와 포트를 선택하세요. 다른 보드의 전원·핀 규격은 별도로 확인해야 합니다.

| 부품 | 연결 |
| --- | --- |
| 일반 순간 누름 버튼 | D2와 GND 사이. 내부 풀업을 사용하며 누르면 LOW입니다. |
| 외부 LED | D9 → 직렬 저항(UNO 예: 330Ω) → LED 긴 다리(+), 짧은 다리(−) → GND |
| USB | 데이터 전송이 가능한 케이블로 컴퓨터와 보드를 연결 |

보드 내장 LED(`LED_BUILTIN`)도 같은 상태를 표시합니다. 외부 LED와 모형을 조립하기 전에 USB 연결부터 검증할 수 있습니다. 4핀 택트 스위치는 같은 쪽 두 핀이 내부에서 연결된 제품이 있으므로, 누를 때만 두 접점이 연결되도록 확인하세요. LED에는 직렬 저항을 사용하세요.

## 업로드와 웹 연결 순서

1. Arduino IDE에서 `semiguard_prototype/semiguard_prototype.ino`를 엽니다.
2. 실제 보드 종류와 USB 포트를 선택하고 업로드합니다.
3. 필요하면 시리얼 모니터를 **115200 baud**로 열어 아래 형식의 JSON 줄이 약 200ms 간격으로 나오는지 확인합니다.
4. **시리얼 모니터·시리얼 플로터 등 포트를 사용하는 프로그램을 닫습니다.** 웹과 IDE가 한 포트를 동시에 사용할 수 없습니다.
5. 데스크톱 Chrome 등 Web Serial 지원 브라우저에서 HTTPS 웹사이트를 열고 USB 연결 버튼을 눌러 해당 보드 포트를 선택합니다.
6. UNO는 포트를 열 때 재시작할 수 있습니다. 정상 신호를 받을 때까지 잠시 기다립니다. 8초 안내가 나타나면 펌웨어·포트·속도와 다른 시리얼 프로그램을 확인합니다.

## 체험 동작

- 시작 시 이상 상태는 해제되고 LED는 켜집니다.
- 물리 버튼을 한 번 누르면 이상 상태가 켜지고 LED가 꺼집니다. 다시 누르면 이상을 해제합니다. 길게 누르고 있어도 한 번만 바뀝니다.
- 웹에서 초기화를 누르면 `RESET <요청번호>\n` 명령을 보냅니다. 펌웨어는 이상 상태를 해제한 뒤 해당 번호를 `resetAck`에 넣어 새 telemetry를 보냅니다. 웹은 **요청번호가 일치하는 정상 응답**을 확인합니다. 버튼을 눌러 정상 상태로 바뀐 것만으로 명령 성공을 판단하지 않습니다.
- 정상 신호를 2초 이상 받지 못하면 웹은 수신 중단으로 표시하고 현재 값 표시를 멈춥니다. 케이블이 끊겨도 가상 값으로 자동 전환하지 않습니다.
- 보드의 물리 RESET을 눌러 순번이 처음으로 돌아갔다면 웹에서도 연결을 끊었다가 다시 연결하세요. 이전 실행의 신호와 새 실행의 신호를 섞지 않기 위한 절차입니다.

## 통신 규약

UTF-8 JSON 한 개당 한 줄(`\n` 또는 `\r\n`)입니다. 순번과 부팅 후 시간은 uint32입니다.

```json
{"kind":"semiguard-prototype","version":1,"seq":0,"uptimeMs":200,"faultActive":false,"ledCommand":"on","resetAck":0}
```

수신 명령은 대소문자를 구분한 `RESET 12345`처럼 **RESET, 공백, 1~4294967295 범위의 요청번호** 한 줄입니다. `resetAck`는 마지막으로 처리한 요청번호이며 0은 아직 요청을 처리하지 않았다는 뜻입니다. 요청번호 없는 RESET은 처리하지 않습니다. 명령 버퍼는 최대 16자로 제한하고, 넘치는 줄이나 알 수 없는 명령은 무시합니다. telemetry에 공정 측정값을 추가해 실제 계측처럼 표시하지 마세요.

## 현장 확인

물리 버튼 → 웹 상태 변화 → LED 반응 → 초기화를 연속해서 여러 번 확인합니다. 연결 해제 시 현재 값이 사라지는지 확인하고, 업로드가 끝난 뒤 IDE의 시리얼 모니터를 닫아 두세요. 화면 데모를 사용할 경우에는 웹의 **화면 데모**를 명시적으로 시작해야 하며, USB 실물 연결과 구분해 설명합니다.
